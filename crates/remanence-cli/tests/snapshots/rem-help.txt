Remanence — library and standalone tape CLI

Usage: rem <COMMAND>

Commands:
  libraries                      List every library `discover()` found on this host
  library                        Focused view of a single library, by serial
  list                           List committed archive paths
  setup                          Check this host and save a default standalone drive
  doctor                         Check permissions and storage readiness
  drives                         Show discovered tape endpoints and ownership
  watch                          Subscribe to OS hot-plug events touching SCSI tape / changer subsystems
  rebuild-catalog-from-journals  Rebuild the local SQLite catalog projection from the audit log and the tape logs
  reset-catalog                  Declare the offline state reset required by an authority-layout change
  daemon                         Query daemon process health and version over Layer 5 gRPC
  op                             Query daemon operation status
  catalog                        Query the daemon catalog
  audit                          Query the daemon's append-only audit log
  drive                          Query and mutate daemon drive stewardship state
  alarms                         List or acknowledge standing daemon alarms
  top                            Live top view over daemon state
  tape                           Manage and inspect tapes in a library or standalone drive
  put                            Archive local files onto a library or standalone tape
  get                            Restore an object from a library or standalone tape
  archive                        Probe, catalog, or restore a dump archive through a format driver
  restore                        Restore a native REM-OBJECT object into a directory
  help                           Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help

  -V, --version
          Print version

Library operations go through the daemon; a standalone drive is operated directly.
For a standalone drive: rem setup, then rem put/get/tape; or pass --device PATH --allow-device SERIAL.
