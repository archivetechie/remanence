# Presence verdicts for Layer 5 wire fields whose zero value is the honest answer.
#
# One line per field:  <Message.field>  <reason the zero value is genuinely correct>
#
# This is a record of DECISIONS TAKEN, not a list of permitted exceptions. A field
# appears here because someone examined it and concluded that zero, empty or false
# is a truthful value for it — not because flattening it was convenient. The reason
# is written down so it can be argued with later.
#
# Every other field must be one of: declared `optional`, an enum carrying its own
# *_UNSPECIFIED = 0, a repeated field, or a submessage. Anything else reads as
# UNEXAMINED in `tools/wire_presence_census.py`, which is the honest state for a
# field nobody has yet considered.
#
# Nested message fields are written with their full path, e.g. Outer.Inner.field.
#
# The count of fields still UNEXAMINED is the work, and it is meant to be visible.
# It is not repeated here, because a hand-kept number rots: this line used to say
# 353 while the census said 252. Run `python3 tools/wire_presence_census.py` for
# the live figure, or count tools/wire-presence-baseline.txt.

# ---------------------------------------------------------------------------
# Drive area, decided 2026-08-06. Derivation for catalog-backed messages is the
# `drives` / `drive_health_snapshots` schema: NOT NULL means the value is always
# known, so the field stays plain. Where the schema says nullable, the field is
# `optional` and does not appear here.
# ---------------------------------------------------------------------------
DriveCatalogEntry.drive_uuid       primary key of the drives table; a row cannot exist without one
DriveCatalogEntry.identity_source  drives.identity_source is NOT NULL; every row records how identity was established
DriveCatalogEntry.actionable       drives.actionable is NOT NULL DEFAULT 1; always a decided boolean
DriveCatalogEntry.managed          drives.managed is NOT NULL
DriveCatalogEntry.state            drives.state is NOT NULL DEFAULT 'active'
DriveCatalogEntry.cleaning_due     drives.cleaning_due is NOT NULL DEFAULT 'none'; 'none' is a value, not an absence
DriveCatalogEntry.fenced           drives.fenced is NOT NULL DEFAULT 0
DriveHealthSnapshot.snapshot_id    primary key; a snapshot cannot exist without one
DriveHealthSnapshot.drive_uuid     NOT NULL; a snapshot is always of a specific drive
DriveHealthSnapshot.trigger        NOT NULL; whoever took the snapshot knows why they took it
Slot.element_address               the address IS the slot's identity; a slot with no address is not a slot
PortalSlot.element_address         as Slot.element_address
DriveAssignment.library_serial     an assignment is always to a named library
DriveAssignment.bay                an assignment is always to a specific bay

# Objects area, decided 2026-08-06. Derived from `objects` / `object_files`.
ObjectRecord.object_id        primary key of the objects table
FileRecord.object_id          object_files.object_id is NOT NULL, half the primary key
FileRecord.file_id            object_files.file_id is NOT NULL, the other half
FileRecord.path               object_files.path is NOT NULL; a catalogued file always has one
FileRecord.size_bytes         object_files.size_bytes is NOT NULL; the writer measured it to catalog it
FileRecord.file_sha256        object_files.file_sha256 is NOT NULL; computed during the write that catalogued it
FileRecord.chunk_count        object_files.chunk_count is NOT NULL
Tape.tape_uuid                primary key of the tapes table

# Sessions area, decided 2026-08-06. The `sessions` table is thin -- most of
# WriteSession is live in-memory state, so the derivation is the session's own
# lifecycle rather than column nullability.
WriteSession.session_id       primary key; a session cannot exist without one
WriteSession.body_format      resolved when the session opens -- the caller's, or the daemon default it declined to name -- so a session always has one
WriteSession.objects_committed a live session is counting; zero at open is a real count, never unknown
WriteSession.bytes_committed  as objects_committed
WriteSession.current_tape_index an index into tape_sequence, always positioned somewhere
WriteSession.pending_checkpoint_objects a counter the session maintains; zero means zero pending
WriteSession.pending_checkpoint_bytes as pending_checkpoint_objects
ReadSession.session_id        primary key; a session cannot exist without one
ReadSession.daemon_epoch      minted with the session by the daemon that created it

# Write-session lifecycle requests, decided 2026-08-06. The rule inverts for a
# request: the CALLER supplies the value, so a required parameter stays plain
# and an absent one is a rejected request, not an Option the server has to
# interpret. That is only true if the server actually rejects it, so each of
# these was read against its handler rather than assumed. Every session_id
# below reaches decode_uuid_bytes (lib.rs), which refuses anything that is not
# exactly 16 bytes -- empty included -- with INVALID_ARGUMENT.
CheckpointSessionRequest.session_id  refused by decode_uuid_bytes; you cannot checkpoint an unnamed session
CloseWriteSessionRequest.session_id  refused by decode_uuid_bytes
AbortWriteSessionRequest.session_id  refused by decode_uuid_bytes
GetWriteSessionRequest.session_id    refused by decode_uuid_bytes
